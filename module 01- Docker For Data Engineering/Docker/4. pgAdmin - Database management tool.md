Now in another terminal we will run pgAdmin *on the same network*
```bash
  docker run -it `
  -e PGADMIN_DEFAULT_EMAIL="admin@admin.com" `
  -e PGADMIN_DEFAULT_PASSWORD="root" `
  -v pgadmin_data:/var/lib/pgadmin `
  -p 8085:80 `
  --network=pg-network `
  --name pgadmin `
  dpage/pgadmin4
```
now we can go to http://localhost:8085/browser/ and login with our pg-admin email and password
and we will start using pg-admin
