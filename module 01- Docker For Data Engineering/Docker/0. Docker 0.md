# Docker

1. **دوكر (Docker)**: هو أداة لإنشاء وتشغيل البيئات البرمجية المعزولة باستخدام مفهوم الحاويات (Containers). 
2. فائدة استخدام دوكر في هندسة البيانات:
	1. الاستقلالية وإعادة الإستخدام: يضمن تشغيل أنابيب البيانات (Data PipeLines) وقواعد المعطيات بنفس السلوك والبيئة على أي جهاز.
	2. عزل البيئات وعدم التضارب بين الإصدارات المختلفة للمكتبات أو قواعد المعطيات. 

المفاهيم الأساسية في دوكر: 
1. الصورة أو Docker Image: هي النموذج الأساسي أو المخطط المعزول، وتتكون الصورة من اسم ورقم الإصدار. 
	مثال: 
	```bash
	python:3.13.11-slim
	# name: python
	# tag: 3.13.11-slim
	```
2. الحاوية أو (Docker Container): هي النسخة الشغالة المأخوذة من الـ Image.
3. تغيير الحالة في الحاويات: الحاويات بطبيعتها Stateless (التعديلات الي منقوم فيا رح يختفي بمجرد إغلاق الحاوية)، لحتى نحسن نحفظ تعديلاتنا لازم ننتقل لشي اسمو Volumes أو Volumes Mapping.
