# inserting the data to postgres
since the data is two big (1.6 m records) we can't insert it at once it will take to much time, instead will split it into chunks and we put these junks one by one,
we will use this to read the data:
```python
df_iter = pd.read_csv(
    prefix + 'yellow_tripdata_2021-01.csv.gz',
    dtype=dtype,
    parse_dates=parse_dates,
    iterator=True,
    chunksize=100000
)
```
now the data is splitted two chunks each of size 1e5
```python
from tqdm.auto import tqdm
	for df_chunk in tqdm(df_iter):
    df_chunk.to_sql(name='yellow_taxi_data',                  con=engine,if_exists='append')
```
and after this step our data is injected to postgres as a table

```bash 
uv add "psycopg[binary]"
```
then to rebuild the image and re run it 

But now we will git an error 
```
psycopg.OperationalError: connection failed: connection to server at "127.0.0.1", port 5432 failed: Connection refused
```
this error is because when running inside a Docker container, `localhost` (and `127.0.0.1`) refers to **the ingestion container itself**, not your host machine or another container. Because Postgres is not running inside this specific container, the connection is refused.
because the local host of our host machine is not the same host on our container.

No we will solve this by creating a shared network 
to create a network in docker we use 
```bash
docker network create pg-network
```
where pg-network is the name of our network 

and to run the docker container on the network we created we modify the docker command or postgres and add the network parameter: 
and we also add names to the two containers so they can see each other:
```bash 
docker run -it --rm `
  -e POSTGRES_USER="root" `
  -e POSTGRES_PASSWORD="root" `
  -e POSTGRES_DB="ny_taxi" `
  -v ny_taxi_postgres_data:/var/lib/postgresql `
  -p 5432:5432 `
  --network=pg-network `
  name pgdatabase `
  postgres:18
```

```bash
docker run -it --rm `
--network=pg-network`
  taxi_ingest:v001 `
  --pg-user=root `
  --pg-pass=root `
  --pg-host=pgdatabase `
  --pg-port=5432 `
  --pg-db=ny_taxi `
  --target-table=yellow_taxi_trips
```
so now the tow containers because part of the same network 

now we run the postgres container in it's own terminal
and the other container in another terminal (but remember to change the host from *localhost* to the name of the postgres container which is *pgdatabase*)
